## Findings fixed before handoff

- A single root-bound exclusive launch receipt and fixed results path prevent a
  second initial invocation. Supervisor and worker OS locks reject concurrent
  work. Workers need a live dispatch ticket and exact request hash; source, plan,
  data and runtime identities are rechecked before optimizer work. This is an
  auditable execution boundary, not a security system against the machine owner.
- Add a supervised, standard-library-only integrity job before CPU tests import
  LatoS. It rehashes the original transfer and installed-wheel Python source.
  Native CUDA setup then binds the original implementation and exact runtime,
  actual GPU, driver, cuDNN and all declared deterministic controls.
- Count initial controller verification from the session start, and include every
  dispatched import/preflight/cache/hash/checkpoint operation in cumulative active
  budgets. Parent watchdog failures stop children; final receipts cannot promote
  an over-budget worker completion. Preparation/test work cannot reset the clock.
- Native checkpoints need a mandatory additional policy record. Save native
  payloads and policy in a staging directory, require exact native/full-state
  readback, then publish the whole completed checkpoint with one rename. Reject
  missing policy, changed data/source/controls/RNG or any incomplete update.
- Use unique staging directory names, preserving old interrupted staging rather
  than overwriting or blocking on its name. The sole deletion is an empty staging
  container after successful publication. Tensor evidence is not removed.
- Preserve actual mismatching replay rows before raising. Every logged overlap
  must match exact state/input/schedule and the unchanged `1e-5` loss criterion
  before any extension beyond it. Torn final lines are retained, not parsed as
  successful updates; unknown physical work receives conservative upper charges.
- Windows mandatory byte locks require hashing through the already-held file
  handle. Pass that handle during recovery preservation checks and return-package
  collection. The return packager acquires both execution locks, refuses a live
  writer and reads its own locked lease bytes through those same handles. The
  common-handle path and lock exclusion run in the focused test suite; the actual
  Windows locking implementation remains to be exercised there.
- The scripted supervisor test originally created dummy environment-named folders,
  which conflicted with the return packager's environment exclusion. Replace those
  dummy trees with an in-memory availability simulation. Scripted child receipts
  remain explicitly distinguished from optimizer execution.
- Final access requires prior complete execution, passing fixed development and
  inference gates, exact reviewed evidence hashes and the locked candidate/Phase 5
  model panel. The unchanged native access checker separately validates the exact
  selection/contamination declaration. Initial execution never dispatches final.
- Source/recipe and dataset/cache identities are checked before training. The
  same-Windows learning-rate table is written once and checked exactly throughout.
  No old cross-host schedule tolerance is imported as a same-host allowance.
- The return preserves all scalar/full-state evidence and includes new final
  candidate bytes if present, regardless of quality. Other tensor payloads remain
  on Windows with inventories; packaging does not imply model acceptance or backup.
  Console logs and every worker/supervisor failure remain evidence.
- Recovery accounting now charges durable rows plus at most one unlogged update,
  rather than reserving the entire unexecuted tail after a second interruption.
  Earlier conservative charges cannot be reset. A two-interruption scripted test
  verifies cumulative charges without performing any optimizer work.
- Source-distribution review found that its explicit include list would omit the

  source-package allowlist only; dependencies, lock and native code remain unchanged.
  A real source build and 35 extracted CPU checks passed with zero optimization.
- Formatting/import findings were corrected. An initial combined patch did not
